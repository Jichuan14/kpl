# 英雄调整

### 芈月-玩法升级-"暗影锁链，群体链接"

感谢大家在《策划打游戏》直播中对芈月的建议和反馈，我们综合对芈月二技能进行优化升级，强化了芈月的团战能力并降低空放惩罚：二技能命中后芈月的仆从会自动搜寻并传导链接给其他未被链接的目标，造成伤害和减速并回复自身生命值，群链至多连接5名敌方单位。除此之外，我们调整了二技能进入冷却的机制并降低了它的冷却时间，同时优化了二技能的释放手感，以降低释放技能时带来的“罚站”感
被动：优化暗影仆从的寻敌逻辑，在目标无自身视野时不会主动发起攻击。
被动：效果调整：对英雄造成 40~80(+0.08Ap) 法术伤害，对非英雄单位提升 100%
一技能：基础伤害： 200(+20/Lv)(+0.24Ap) → 150(+30/Lv)(+0.3Ap)
二技能：新增效果：锁链可连锁至附近敌人，可额外连接目标 2/3/4 （技能等级达到 3,5 时提升 )
二技能：技能手感优化
二技能：效果调整：锁链每命中一个单位获得 35(+7/Lv)(+0.5% 额外生命 ) 回复 ( 非英雄单位减半 ) ，并对目标造成 35(+7/Lv)(+0.07Ap)(0.5 秒 1 次，持续 4 秒 ) 法术伤害与至多 15%(+3%/Lv) 减速 ( 逐渐增加， 4 秒达到上限 ) 。芈月的普攻造成 25(+5/Lv)(+0.15Ap)(+1.0Ad) 法术伤害并在命中时获得 10 暗影之力
二技能：冷却时间： 9 → 6.5(-0.3/Lv)
二技能：效果调整：施法后进入冷却 → 链接结束后进入冷却
三技能：冷却时间： 24(-2/Lv) → 25(-2.5/Lv)
三技能：移速加成： 30% → 70(+35/Lv)
三技能：基础伤害： 380(+190/Lv)(+0.7Ap) → 350(+175/Lv)(+0.7Ap)
