# 6月25日王者荣耀小游戏版本更新公告

## Source boundary

This is a normalized primary-source announcement. It establishes the
announced game changes only; it does not establish a KPL pick/ban, win-rate,
or optimal-draft effect without separate date-scoped KPL data evidence.

## Announcement content

【更新时间】 我们已于 6月25日6:00-8:00 完成王者荣耀小游戏版本更新
【更新方式】 不停机更新
【体验方式】 微信内搜索“王者荣耀 小游戏”，点击对应结果进入即可
【更新内容】
新增适配多种机型
以下机型可以游玩王者荣耀小游戏：
安卓运行内存6G以上设备，IOS运行内存6G以上且ios17以上设备，鸿蒙运营内存6G且微信8.0.17版本及以上设备（鸿蒙QQ暂未支持）
战令开启
赛季战令可在王者荣耀小游戏使用了，个性化道具、星元等物品可获取，但暂不支持在小游戏使用，可在王者荣耀app正常使用
礼册开启
礼册可在王者荣耀小游戏使用了，个性化道具可获取，但暂不支持在小游戏使用，可在王者荣耀app正常使用
