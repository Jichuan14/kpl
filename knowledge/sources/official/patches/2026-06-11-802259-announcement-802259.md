# 英雄调整

### 鲁班大师

为了提升鲁班大师的主动性和单兵作战体验，我们为二技能新增了可以链接墙体并向墙体位移的机制，并且升级了大招和被动强普的表现和机制细节。
被动：效果调整：技能施放或命中获得护盾 → 施放技能获得护盾
被动：护盾效果： 150~300(+0.2Ap)(+3% 额外生命 )( 持续 5 秒，上限 4 层 ) → 250~500(+5% 额外生命 )( 持续 5 秒，上限 3 层 )
被动：强化普攻：额外造成 400~820(+0.4Ap) 法术伤害 (CD:5 秒 ) → 额外造成 200~400(+0.33Ap) 法术伤害，短暂延迟后造成等量 300~600(+0.5Ap) 法术伤害 (CD:6.5~5 秒 )
一技能：基础伤害： 500(+100/Lv)(+0.5Ap) → 450(+90/Lv)(+0.7Ap)
二技能：助手驰援
冷却时间： 10(-0.2/Lv) ，结束 / 互动后进入冷却 → 12.5(-0.5/Lv) ，使用后进入冷却
选中队友：鲁班大师获得 75(+15/Lv) 加速 (1 秒内衰减 ) 和一名队友创造链接 ( 持续 4 秒 ) ，为其提供 35(+7/Lv)(+0.7% 额外生命 ) 护盾 ( 每 0.5 秒 1 层，上限 8 层 ) ，队友确认交互后会立即位移到鲁班大师的位置
选中墙体：鲁班大师将自身牵引至墙体 ( 由近到远进入 50%~100% 冷却 )
三技能：强力收纳
冷却时间： 40(-5/Lv) → 45(-4.5/Lv)
鲁班大师向前方扇形区域发射机械臂连接区域内的敌人 ( 最多 6 个，优先英雄 ) ，每条机械臂造成 120(+60/Lv)(+0.2Ap) 法术伤害 ( 多次命中衰减至 25%) ，距离过远时连接会提前断开造成等量伤害并将目标向自身方向牵引一小段距离连接 1.25 秒后鲁班大师将连接的敌人牵引至身边并造成晕眩 ( 持续 1 秒 ) ，每条机械臂造成 300(+150/Lv)(+0.5Ap) 法术伤害 ( 多次命中衰减至 25%)
