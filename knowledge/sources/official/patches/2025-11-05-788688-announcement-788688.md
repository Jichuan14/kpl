# 英雄调整

### 元流之子-辅助

二技能：新增机制：友方英雄(包含自己)离开施法台时会朝移动方向触发跃迁
二技能：施法台上连续释放：新施法台位置不变 → 新施法台移动到自身所在位置
二技能：施法台上连续释放：新施法台持续时间重置为4秒 → 新旧施法台的持续时间可叠加
二技能：视野范围：1000/1250/1500 → 950/1100/1250
二技能：护盾效果：400(+80/Lv)(+6%额外生命) → 320(+64/Lv)(+5%额外生命)
三技能：基础伤害：80(+40/Lv)(+0.12Ap) → 84(+42/Lv)(+0.13Ap)
三技能：效果调整：音波弹射后伤害衰减至75%(不重复衰减)

### 曹操

一技能：小幅降低位移速度

### 嫦娥

三技能：基础伤害：75(+0.1Ap) → 70(+0.09Ap)

### 雅典娜

一技能：基础伤害：400(+80/Lv)(+1.4额外Ad) → 375(+75/Lv)(+1.25额外Ad)

### 花木兰

被动：轻剑状态：新增效果：叠满印记获得80~160(+1%额外生命)回复
被动：轻剑状态：新增效果：可对非英雄单位叠加平衡印记，叠满时造成的伤害和回复效果减半
三技能：重剑状态：提升攻击力：60(+120/Lv) → 90(+90/Lv)
