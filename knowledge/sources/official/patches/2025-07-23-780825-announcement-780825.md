# 英雄调整

### 嫦娥

被动伤害：110~220(+0.18Ap) → 100~200(+0.2Ap)
二技能：伤害减免：10% → 6%(+1.2%/Lv)
三技能：基础伤害：80(+0.1Ap)→ 75(+0.1Ap)

### 杨戬

三技能：冷却时间：30(-3/Lv) → 35(-3.5/Lv)

### 曹操

曹操手感优化提升效果显著，我们回调了上次对于二技能冷却的改动
二技能：普攻降低冷却比例：10% → 5%(+1%/Lv)

### 少司缘

二技能：持续伤害：45(+9/Lv)(+0.06Ap) → 40(+8/Lv)(+0.07Ap)
二技能：结束伤害：225(+45/Lv)(+0.3Ap) → 200(+40/Lv)(+0.35Ap)
二技能：附身伤害：630(+126/Lv)(+0.85Ap) → 640(+128/Lv)(+0.95Ap)

### 猪八戒

被动：基础转血比例：对英雄40%/非英雄15% → 对英雄40%(非英雄减半)

### 裴擒虎

三技能：切换形态：增加移速:15%(+5%/Lv) → 25(+25/Lv)

### 蒙恬

优化特定英雄对蒙恬的极端克制体验
三技能：新增效果：蒙恬士兵免疫印记效果

### 刘备

平衡刘备的前后期作战能力，并优化其增加减冷却机制后的蓝耗体验
二技能：效果调整：每颗弹丸命中减少2%冷却 → 首发弹丸命中减少5%冷却，后续弹丸命中减少1%冷却
二技能：蓝耗：55 → 45
三技能：护盾转化比例：25%(+12.5%/Lv) → 固定40%

### 弈星

优化弈星三技能冷却成长不足的问题
三技能：冷却时间：60(-2.5/Lv) → 60(-5/Lv)

### 元流之子(坦克)

三技能：施法距离：500 → 525
