# 英雄调整

### 大禹

大禹辅助能力全面升级，岩簇群控，鼎拓视野，我们对大禹的整体机制进行了重新整合和升级，调整后大禹有着更聚焦更强大的辅助能力和控制能力
基础属性
攻击范围：近战 → 远程
基础生命：3525(+320*英雄等级) → 3450(+315*英雄等级)
物理防御：150(+18.5*英雄等级) → 150(+18*英雄等级)
法术防御：75(+7.4*英雄等级) → 75(+9.5*英雄等级)
被动：九鼎齐鸣
大禹可召唤九鼎，学习【乾坤以同】后靠近鼎时【回城】切换为【传送】，可将自身传送至任一鼎，传送期间获得霸体
戍鼎放置上限：初始3个，每3级增加1个，上限8个
一技能：随山定势
大禹向指定位置召唤戍鼎并提供视野，友方英雄在靠近戍鼎时获得累计300(+60/Lv)(+6%额外生命)回复(CD:20秒)同时大禹自身获得75(+15/Lv)加速(2.5秒内衰减，自身生命满时不消耗能量生效50%)
二技能：辟命狩天
大禹向指定方向召唤岩簇并在到达终点或命中首个目标时爆裂，沿路径连续3次造成400(+80/Lv)(+1.2额外Ad)物理伤害和0.75秒击飞(控制效果逐次衰减，近距离击退)，同时自身进入狩天状态获得3次强化普攻，每次造成125(+25/Lv)(+0.75Ad)物理伤害并使自身获得70(+14/Lv)(+1.4%额外生命)回复(非英雄减半)
三技能：乾坤以同
大禹召唤乾鼎(落地后存在8秒)砸向目标区域造成击飞(持续1秒)和500(+250/Lv)(+1.45额外Ad)物理伤害(中心区域额外造成0.25秒击退和50%伤害)
二段：大禹自身传送至乾鼎并获得爆发加速(2.5秒内衰减)，同时引发【震荡波】造成100(+50/Lv)(+0.3额外Ad)物理伤害和15%(+7.5%/Lv)减速(持续1秒)，传送期间获得霸体
